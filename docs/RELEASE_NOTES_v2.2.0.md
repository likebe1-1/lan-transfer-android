# LanLink v2.2.0 发布说明

> 版本：v2.2.0（versionCode 10）
> 包名：com.manst.lantransfer（覆盖安装可直接保留数据）
> 发布日期：2026-11-15

## 本次重点

### 1. 应用内更新（新增）
- 启动时静默检查更新，首页顶栏也可手动「检查更新」；
- 更新清单多源拉取（jsDelivr / GitHub raw / ghproxy 镜像），任一可用即可；
- 下载走 GitHub Releases 多镜像，校验「大小 + SHA-256 + APK 签名」后拉起系统安装；
- GitHub 不可用时提供「蓝奏云浏览器下载」兜底（密码自动复制）；
- 检查中显示「正在检查更新…」，失败可重试。

### 2. 快速传文件安全加固
- UDP 广播不再携带接收码，只广播设备名/IP/端口/协议；
- 接收方点击附近设备后需输入 6 位接收码；
- 同一目标连续 5 次接收码错误后锁定 10 分钟（应用内限流）。

### 3. 中英文界面
- 全部界面文案资源化（strings.xml）；系统语言为英文时自动显示英文界面；
- 动态提示（Snackbar/部分错误文案）暂仍为中文。

### 4. 第一批体验功能
- 快速传文件「接收断点续传」：FTP/FTPS/SFTP 中断后从分片断点继续，SCP 仍整文件重传；
- 「收到文件自动保留」：快速传文件会话结束时，对方发回的文件自动保存到系统「下载」目录；
- 「共享目录自动刷新」：本机服务器页可见时约每 5 秒静默刷新；
- 「通知栏操作」：进度通知新增「取消」，一键取消全部活动传输；
- 「桌面快捷方式」：长按桌面图标直达「发送文件 / 接收文件 / 启动服务器」。

### 5. 网络工具（新增）
- 首页顶栏进入：查看本机 IP/子网/网关/接口；
- 扫描同网段设备（IP、MAC、主机名、开放端口、设备类型），识别正在等待接收的 LanLink 设备；
- 网络诊断：同网段 / 网关可达 / 设备发现 / LanLink 设备 / 疑似 AP 隔离提示；
- 任意 IP:端口 TCP 连通性测试。

### 6. 一键组网（热点，新增）
- 没有路由器或 AP 隔离时：A 手机开热点，LanLink 生成「热点二维码」；
- B 手机扫码后由 App 自动加入热点（应用级 Wi-Fi，不修改系统 Wi-Fi 设置），随后回到快速传文件互传；
- 支持尝试读取当前热点信息自动填充，失败可手动输入；
- 注意：Android 不允许普通 App 直接开关热点，A 仍需在系统设置中手动开启。

### 7. 问题修复
- 修复恢复未完成任务时前台服务启动顺序问题，避免 ForegroundServiceDidNotStartInTimeException 崩溃；
- 修复「检查更新」点击无反馈、离线长时间等待、并发拉取崩溃的问题；
- 修复 Activity 处理快捷方式时修改 intent.action 导致系统/测试认为 Intent 不一致的问题；
- 修复快速传文件进度用例在快速完成时的偶发失败（测试稳定性）。

## 已知限制
- 应用内更新依赖 GitHub/jsDelivr/镜像可访问；全部不可用时请使用蓝奏云浏览器下载；
- 一键组网需手动开启热点；热点信息读取在部分系统上会失败（可手动填写）；B 的加入为应用级 Wi-Fi，部分厂商 ROM 可能弹出确认；
- 网络工具基于常见端口探测，未开放这些端口的设备可能扫不到；AP 隔离提示为启发式；
- 快速传文件单次最多 200 个文件；接收端续传仅 FTP/FTPS/SFTP；SCP 不支持断点续传；
- 服务器模式仅单用户、单共享目录、被动模式；FTPS 自签证书在进程重启后重新生成；
- 动态 Snackbar/部分错误文案暂未英文化。

## 校验与构建
- 基于 tag v2.2.0 构建；Release APK 已签名（证书与旧版本一致）；
- 单测 265 个、设备仪器测试 65 个全部通过（API 29 模拟器）；真机功能测试见仓库文档。
