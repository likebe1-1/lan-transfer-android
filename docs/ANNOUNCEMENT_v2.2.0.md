# LanLink v2.2.0 发布公告（可直接复制发布）

【LanLink v2.2.0 发布】局域网传文件，更安全、更好用

LanLink 是一个纯局域网互传文件的小工具（不用登录、不上传云端、不收集数据），支持 FTP / FTPS / SFTP / SCP 四种协议，也能在手机上直接开服务器、让电脑或其他手机访问。

本次 v2.2.0 更新：

- 应用内更新：以后可直接在 App 里检查并下载新版本（GitHub 多镜像）；GitHub 访问不了时可用蓝奏云下载兜底。
- 快速传文件安全加固：局域网广播不再泄露接收码；附近设备需输入 6 位接收码；连续 5 次输错锁定 10 分钟。
- 中英文界面：系统语言为英文时自动显示英文。
- 第一批体验功能：快速传文件接收断点续传；对方发回的文件自动保存到「下载」；本机服务器共享目录自动刷新；传输通知栏「取消」按钮；桌面长按图标直达「发送文件 / 接收文件 / 启动服务器」。
- 网络工具：局域网设备雷达 + 网络诊断（同网段/网关/AP 隔离提示）+ IP:端口测试，快速定位「为什么连不上」。
- 一键组网：没有路由器或路由器开了 AP 隔离？A 开热点生成二维码，B 扫码自动加入，再传文件。
